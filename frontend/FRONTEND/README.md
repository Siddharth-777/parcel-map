# GEO-DRAFT

AI-assisted urban cadastral mapping platform. Generates preliminary parcel boundaries, building footprints, and road corridors from high-resolution drone imagery (ORI), DSM/DTM elevation models, and GNSS/CORS survey data.

Aligned with NAKSHA (DoLR) and TNGIS (TNeGA/COSS) standards for Indian land record modernization.

## Tech Stack

- React 19 + Vite
- Tailwind CSS 4
- Leaflet / React-Leaflet (map rendering)
- Framer Motion (animations)
- Lucide React (icons)

## Run Locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
